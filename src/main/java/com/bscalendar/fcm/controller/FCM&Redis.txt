1. Web -> FCM : Firebase SDK를 통해 FCM에 등록을 요청

2. FCM -> Web : 고유한 Token 발급

3. Web -> Server : Web에서 받은 토큰을 데이터베이스에 저장

4. 알림 메시지 전송
   Server -> FCM : 알림이 전송되는 이벤트 발생 -> 서버에 저장된 FCM 토큰과 함께
   알림의 내용을 메시지 페이로드에 담아 FCM 서버로 알림 전송을 요청

5. FCM -> 전송 계층 -> Web
   1. FCM 서버는 전송 요청을 받고
   2. 토큰을 이용해 클라이언트 식별
   3. 웹의 경우 웹 푸시 프로토콜을 통해 알림을 전달
   4. 웹 브라우저의 서비스 워커가 알림을 수신하고 사용자에게 팝업 알림 형태로 표시

FCM : 웹 브라우저가 꺼져 있어도 알림을 보낼 수 있고 구글의 인프라를 사용가능
Redis : 메모리기반의 DB

로그인 -> 고유 토큰(FCM에서 주는 휘발성 토큰 f12눌러서 확인가능) 발급 -> FcmController로 전송 -> Redis에 저장
업무&댓글 등록 -> 서비스에서 DB에 저장 후 -> 알림을 보낼 대상 여부 판단
redis에서 저장된 토큰제공

try-catch로 알림은 오류가 나도 DB에 업무&댓글은 저장
